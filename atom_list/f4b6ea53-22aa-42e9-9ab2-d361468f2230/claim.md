## Claim

The paper defines the reinforcement learning setting as an infinite-horizon discounted Markov Decision Process (MDP) specified by the tuple $(\mathcal{S}, \mathcal{A}, P, r, \rho_0, \gamma)$, where $\mathcal{S}$ is the state space, $\mathcal{A}$ the action space, $P: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \to \mathbb{R}$ the transition probability, $r: \mathcal{S} \to \mathbb{R}$ the reward function, $\rho_0$ the initial state distribution, and $\gamma \in (0,1)$ the discount factor. Standard value functions are defined: the state-action value $Q_\pi(s,a)$, the state value $V_\pi(s)$, and the advantage function $A_\pi(s,a) = Q_\pi(s,a) - V_\pi(s)$. The expected discounted return is $\eta(\pi) = \mathbb{E}_{s_0, a_0, \ldots}\left[\sum_{t=0}^{\infty} \gamma^t r(s_t)\right]$.
